# AgentTrace Feedback

Public feedback tracker for the AgentTrace MVP.

AgentTrace is a small browser-local tool for developers who use AI coding agents. It turns an AI-generated diff, PR summary, or agent log into a human review checklist before merge or deploy.

- Try the MVP: https://agenttrace.pages.dev/
- Watch the 48-second demo: https://25a9d298.agenttrace.pages.dev/douyin/agenttrace-demo.mp4
- Leave feedback: https://github.com/yundblue/agenttrace-feedback/issues/1

## What Feedback Helps

Please comment on the feedback issue with any of these:

1. Do you manually review AI-generated diffs today?
2. What change worries you most: auth, database, config, UI, deploy, or something else?
3. Which product surface fits your workflow: web tool, GitHub Action, PR Bot, or AI agent log audit?
4. Would you share an anonymized diff or PR snippet for testing?
5. If this became a GitHub integration, would you consider individual monthly pricing, team seats, or only a free version?

## Evidence Boundary

- This public repo is only for feedback and validation.
- The product source repo remains private during the MVP validation phase.
- Owner progress notes are not counted as external market feedback.
- Please do not post secrets, private source code, customer data, or sensitive production details.
